Meldingen

Discord-meldingen en een waarschuwing als de server offline gaat
Discord
Waar vind ik die?
  1. Webhook: in je Discord-server naar Server Settings → Integrations → Webhooks → New Webhook, kies het kanaal en klik op Copy Webhook URL.
  2. User ID: zet User Settings → Advanced → Developer Mode aan, klik daarna met rechts op je eigen naam en kies Copy User ID.
  3. Een tag geeft een push-melding op je mobiel en pc, ook als je het kanaal gedempt hebt.
Het overzicht bevat de resultaten van de afgelopen 24 uur, je open posities, de signalen en een korte analyse door de AI (één AI-call per dag).
Server offline-melding (heartbeat)
Als je server uitvalt, kan vetobot zelf niets meer sturen. Daarom stuurt hij na elke check een seintje naar een externe dienst. Blijven die uit, dan stuurt díe dienst jou een melding.
–
Zo stel je het in met healthchecks.io (gratis)
  1. Maak een account op healthchecks.io en klik op Add Check.
  2. Zet bij Period je check-interval () en bij Grace Time bijvoorbeeld 10 minuten.
  3. Kopieer de ping URL (https://hc-ping.com/…) en plak hem hierboven.
  4. Ga naar Integrations en kies Webhook. Zet bij Execute when a check goes down: method POST, URL = je Discord-webhook, header Content-Type: application/json en als body:
    {"content": "<@JOUW_ID> vetobot is offline ($NAME)"}
  5. Doe hetzelfde bij Execute when a check goes up met bijvoorbeeld {"content": "vetobot is weer online"}.
Liever zonder tag? Kies bij Integrations dan gewoon Discord.
